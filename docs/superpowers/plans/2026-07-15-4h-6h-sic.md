# 4H- and 6H-SiC Presets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two CIF-backed, basal-cut SiC scan presets: 4H-SiC `(0004)` and 6H-SiC `(0006)`.

**Architecture:** The immutable material catalog remains the sole configuration boundary. Two P1 bundled CIFs supply complete 4H/6H crystal bases; `materials.toml` projects them into pinned symmetric-cut presets. Existing catalog, crystallography, and sweep tests establish the behavior, while the serialized golden fixture records the resulting derived physics.

**Tech Stack:** Python 3.12, NumPy, pytest, TOML, CIF, `crystals` 1.7, uv.

## Global Constraints

- Keep the existing default material scan grid; add no grid controls or transport-model code.
- Use `[0, 0, 1]` beam axes and only `±(0004)` / `±(0006)` reflection families.
- Preserve the unrelated modified analysis files in the current working tree.
- CIF comments must give provenance, assumptions, `V=(sqrt(3)/2)a^2c`, Si:C stoichiometry, finite-coupling limiting checks, and the validation ID.
- Ledger rows remain `unverified` and make no experimental PXR/CBS-performance claim.
