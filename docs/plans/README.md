# Plans & handoffs (tracked, ephemeral)

Single-use planning and handoff notes — what a piece of work intended to do and
how it was handed off — captured at their authoring dates. Tracked (so history
and review survive) but **ephemeral**: superseded by the shipped code and by the
durable docs one directory up.

For current behavior use the generated
[`../cli-reference.md`](../cli-reference.md) and the design/reference docs in
[`../`](../). Accepted decisions live in [`../adr/`](../adr/); long-form
rationale lives in the `*-rfc.md` files.

A plan here that shipped code actively cites as an authoritative decision source
has graduated to reference material — promote it (keep it in `docs/` and give it
an ADR entry) rather than leaving it in this bucket.
