# Physics review checklist for any physics modification

# Use this skill when

Use this skill when modifying or adding any physics equation, scattering model, or transport algorithm. See `/physics:review` for a full structured review command.

# Checklist

- Verify units.
- Check coordinate systems and handedness.
- Verify normalization.
- Check limiting cases (zero thickness, low/high energy, vanishing scattering).
- Compare against analytic results or published figures if available.
- Add a `Validation: <id>` marker and a row in `docs/physics-validation-ledger.md`.
