# Caveman Help

Print concise reference; do not change or claim persistent mode.

| Command | Result |
|---|---|
| `/caveman lite` | Tight full sentences |
| `/caveman` | Full terse mode |
| `/caveman ultra` | Minimum unambiguous prose |
| `/caveman wenyan[-lite|-full|-ultra]` | Classical Chinese variants |
| `/caveman-commit` | Terse Conventional Commit |
| `/caveman-review` | Finding-only code review |
| `/caveman-compress <file>` | Compress natural-language file |
| `/caveman-help` | This reference |

Stop with `stop caveman` or `normal mode`. Preserve user's language, technical
terms, code, commands, and exact errors.
